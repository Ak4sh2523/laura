A key entered here stays in memory by default and is cleared when you reload. Browser-side keys can be inspected by anyone with access to this page. For public deployment, use a backend proxy and keep the secret on the server. Real web search, remote memory, and model discovery require backend support and are not enabled here.

Reasoning / Thinking displays only a separate reasoning field explicitly returned by your API (for example, reasoning_content or reasoning). The selected model and inference server must support and expose that field; frontend settings cannot enable hidden reasoning.

For an iPhone connecting to an API running on your Ubuntu PC, replace 127.0.0.1 with your PC's LAN IP address, e.g. http://192.168.1.20:8642/v1/chat/completions. Both devices must be on the same trusted network, and your API must be configured to listen on the LAN interface and allow the page's CORS origin. Do not expose the API openly to the internet.
